# SeaCrew Prototype

Інтерактивний прототип застосунку для моряків (проєкт «Project scope clarification»).

## Файли

| Файл | Опис |
|------|------|
| `index.html` | Прототип: перемикач A (перший прототип) / B (TestFlight) / C (нова реєстрація й застосунок) — головна сторінка на GitHub Pages |
| `prototype-v1.html` | Перший прототип (вкладка A) |
| `registration.html` | Переадресація на `index.html` (стара адреса) |
| `SeaCrew Prototype.html` | Прототип (EN) |
| `SeaCrew Prototype (RU).html` | Прототип (RU) |
| `SeaCrew Prototype.dc.html`, `seacrew-export.dc.html` | Експорт прототипу |
| `ios-frame.jsx` | Компонент iOS-рамки |
| `support.js` | Рантайм прототипу |
| `uploads/DESIGN_BRIEF.md` | Дизайн-бриф |

## Локальний перегляд

Просто відкрийте `index.html` у браузері — жодних залежностей чи збірки не потрібно.
